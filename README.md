# Python & Bash — DevOps Assignment

- `assignment2_1.py`: grade checker using conditionals.
- `assignment2_2.py`: add/update/list student grades in a dictionary.
- `assignment2_3.py`: prompt for text and write it to `student.txt`.
- `assignment2_4.py`: read and display `student.txt` using `file.read()`.
- `Documentation.docx`: task explanations and execution screenshots.
- `screenshots/`: representative test-output captures.

## Run from this folder
```bash
python assignment2_1.py
python assignment2_2.py
python assignment2_3.py
python assignment2_4.py
```
Use `python3` instead if required by your system.
